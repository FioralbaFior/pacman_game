# Team Organization

This repository is organized for a single 42 learner (`ffrasher`). The learner owns final technical decisions, tests, defense explanations, release upload, and any code changed during peer review.

AI assistance was used for scaffolding, requirements mapping, repetitive documentation, and review suggestions. AI is not treated as an owner or team member: the learner must inspect, understand, test, and be able to modify every submitted line.

Decisions are documented in `ANALYSIS.md`, risks in `RISKS.md`, and validation criteria in `ACCEPTANCE_TEST_PLAN.md` so changes can be reasoned about rather than made ad hoc.
